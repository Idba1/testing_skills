## Short presentation script
"I designed seven reusable software-testing skills following the seven specification components on Week 12's slide 6. Each skill defines input, processing rules, safety constraints, output, validation and failure handling. Four skills have deterministic helpers because numeric boundaries, CSV linkage, workload arithmetic and record validation benefit from reproducible Python. The other three are deliberately advisory because requirements interpretation, test automation review and threat modeling require context and human judgment. I used Week 10's exact nine output-evaluation dimensions and risk tiers and did not invent scoring weights. The scripts were executed on synthetic data, and the unit test suite passed; these results are not claims that a live system was tested."
